## Featured Project

### [OptiX](https://github.com/mazizturki/optix)

**FTTH Network Anomaly Detection Platform**

An intelligent platform designed to detect and analyze anomalies in **FTTH networks** using machine learning and network business rules.

The ML pipeline follows the **CRISP-ML(Q)** methodology and evaluates multiple unsupervised learning algorithms, including:

- Isolation Forest
- One-Class SVM
- Elliptic Envelope

**Isolation Forest** was selected as the production model based on model performance and inference efficiency.

**Architecture & Stack**

`FastAPI` · `React` · `TypeScript` · `Keycloak` · `PostgreSQL` · `Redis` · `MLflow` · `n8n` · `Docker`
